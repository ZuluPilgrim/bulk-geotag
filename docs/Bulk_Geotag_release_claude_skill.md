# Bulk GeoTag release

Guide Fred through publishing a new version of Bulk GeoTag. The project lives in `~/dev/bulk-geotag` on his Linux Mint machine; the repo is public at https://github.com/ZuluPilgrim/bulk-geotag.

## How to work

- **One step at a time.** Give one step, wait for the pasted terminal output, check it, then give the next. Never batch several steps.
- Give exact, paste-ready commands. When delivering files, send them with a SHA-256 checksum to verify (`sha256sum -c`), bundling several files as a `.tar.gz` plus a checksum list.
- **Log build times** (local Linux build, Windows and macOS Actions runs) using the run timestamps, and ask whether to add them to `docs/DEVELOPMENT_TIME.md`.
- Ask for the new version number and a one-line summary of what changed before starting.

## Background

- Version lives in **three** places: `package.json`, `src-tauri/tauri.conf.json` (`version`) and `src-tauri/Cargo.toml` (`version = ...` under `[package]`).
- Linux packages (.deb, .rpm, AppImage) are built **locally** with `npm run tauri build`; output in `src-tauri/target/release/bundle/{deb,rpm,appimage}/` with spaces in names (`Bulk GeoTag_<V>_amd64.deb` etc.).
- Windows (`.msi`, `setup.exe`) and macOS (universal `.dmg`) are built by GitHub Actions (`release-windows.yml`, `release-macos.yml`) when a `v*` tag is pushed. Both workflows upload to the tag's release and rename `Bulk.GeoTag_*` → `bulk-geotag_*` themselves (macOS also deletes the `.app.tar.gz`).
- Windows installers are unsigned (SmartScreen); macOS is **untested on a Mac** and not notarised. Release notes must say both.
- `SHA256SUMS.txt` must be regenerated by hand after all uploads.

## Steps

### 1. Pre-flight
```bash
cd ~/dev/bulk-geotag
git status -sb
git pull
npm run check 2>&1 | tail -1
(cd src-tauri && cargo test --lib 2>&1 | tail -4)
```
Expect a clean tree, `0 ERRORS`, and `test result: ok`.

### 2. Bump the version (replace V and OLD)
```bash
V=1.3.0; OLD=1.2.0
node -e 'const fs=require("fs");for(const f of ["package.json","src-tauri/tauri.conf.json"]){const j=JSON.parse(fs.readFileSync(f));j.version=process.argv[1];fs.writeFileSync(f,JSON.stringify(j,null,2)+"\n")}' "$V"
sed -i "0,/^version = \"$OLD\"/s//version = \"$V\"/" src-tauri/Cargo.toml
grep -m1 '"version"' package.json; grep -m1 '"version"' src-tauri/tauri.conf.json; grep -m1 '^version' src-tauri/Cargo.toml
```
All three must show the new version.

### 3. Update CHANGELOG.md
Add a `## [<V>] - <date>` section at the top (Added / Changed / Fixed). Prepare it as a file with a checksum, or give a small edit.

### 4. Build the Linux packages locally (~5–10 min)
```bash
npm run tauri build 2>&1 | tail -8
```
Expect `Finished 3 bundles` (deb, appimage, rpm). Note start/finish time.

### 5. Commit, tag and push (this starts the Windows and macOS builds)
```bash
git add -A && git status --short
git commit -m "v$V: <summary>"
git tag "v$V"
git push origin main "v$V"
```
The push must show `* [new tag]`.

### 6. Wait for the Actions builds
```bash
gh run list --limit 2 --json name,status,conclusion,createdAt,updatedAt
```
Repeat until both `Release (Windows)` and `Release (macOS)` show `completed` / `success`. Log their durations. On failure: `gh run view <id> --log-failed | tail -40`.

### 7. Upload the Linux packages (renamed without spaces)
```bash
B=src-tauri/target/release/bundle; mkdir -p /tmp/bgrel && rm -f /tmp/bgrel/*
cp "$B/deb/Bulk GeoTag_${V}_amd64.deb"           /tmp/bgrel/bulk-geotag_${V}_amd64.deb
cp "$B/rpm/Bulk GeoTag-${V}-1.x86_64.rpm"        /tmp/bgrel/bulk-geotag-${V}-1.x86_64.rpm
cp "$B/appimage/Bulk GeoTag_${V}_amd64.AppImage" /tmp/bgrel/bulk-geotag_${V}_amd64.AppImage
gh release upload "v$V" /tmp/bgrel/*
```

### 8. Regenerate checksums for every package
```bash
rm -rf /tmp/bgsum && mkdir /tmp/bgsum && cd /tmp/bgsum
gh release download "v$V" -R ZuluPilgrim/bulk-geotag -p 'bulk-geotag*'
sha256sum bulk-geotag* > SHA256SUMS.txt && cat SHA256SUMS.txt
gh release upload "v$V" SHA256SUMS.txt -R ZuluPilgrim/bulk-geotag --clobber
cd ~/dev/bulk-geotag
```
Expect 6 lines (deb, rpm, AppImage, setup.exe, msi, dmg).

### 9. Release notes and title
```bash
gh release edit "v$V" --title "Bulk GeoTag $V" --notes "Bulk GeoTag $V for Linux, Windows and macOS.

<summary of changes>

Linux: .deb (Mint/Ubuntu/Debian), .rpm (Fedora/openSUSE) or AppImage (any distro).
Windows 10/11: bulk-geotag_${V}_x64-setup.exe (or the .msi). Not code-signed: if SmartScreen says 'Windows protected your PC', click More info, then Run anyway.
macOS (Apple Silicon and Intel): bulk-geotag_${V}_universal.dmg. NOT TESTED on a Mac (no Mac hardware available). Not signed or notarised: right-click the app, then Open, or run: xattr -cr \"/Applications/Bulk GeoTag.app\"

Verify downloads with SHA256SUMS.txt. See CHANGELOG.md for details."
gh release view "v$V" --json assets -q '.assets[].name'
```

### 10. Verify and wrap up
- Install the .deb locally (`sudo apt install ./bulk-geotag_${V}_amd64.deb` from `/tmp/bgrel`) and launch from the menu.
- Optionally test the Windows installer on the Windows VM.
- Offer to log build times in `docs/DEVELOPMENT_TIME.md`.
